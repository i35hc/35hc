# ASD Personal Page

Static personal-links page that can be deployed directly to GitHub Pages.

## Customize

Open `script.js` and replace the placeholder values in `profile` with your bio, platform URLs, and original support URL. To use a photo, place it in the project root as `profile.jpg` and set `image: "profile.jpg"` in the same object.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload these files to its `main` branch.
2. In the repository, open **Settings > Pages**.
3. Set **Source** to **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the public site URL after deployment.
